# CrewBot identity

CrewBot is a company workspace for teams directing AI employees. The mark groups three crew members around one friendly face: a team, with a shared point of contact.

| Token | Default | Purpose |
| --- | --- | --- |
| Accent / `--iris` | `#e76e56` | Main actions and ownership highlights |
| Navigation / `--nav` | `#1d3440` | Sidebar and dark brand surfaces |
| Background / `--cloud` | `#eef4f7` | Workspace canvas |
| `--on-accent` | `#172b35` | Text on the default accent |
| `--on-nav` | `#edf5f7` | Text on the default navigation |
| Paper | `#ffffff` | Conversations and work surfaces |

Dashboard appearance is company-specific. The application sets contrast-aware foreground colors when applying user colors. Upload a PNG, JPEG or WebP company logo in Settings. The product identity remains CrewBot on the public landing page; the workspace can carry the company identity.

Native type: Bahnschrift for display and Segoe UI for body, with Trebuchet MS/Arial fallbacks. The interface downloads no external font. `web/brand/icon.svg` and `symbol.svg` are scalable 64×64 marks; `logo.svg` contains the wordmark.

The landing-page diagram is labelled as an illustration. It shows a real sequence—business goal, Mentor, specialists, owner review—without implying connected accounts, completed work or a hosted always-on service.
